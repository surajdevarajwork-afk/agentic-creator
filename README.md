# The Agentic Creator Masterclass · starter kit

The class files for **The Agentic Creator Masterclass** by Evolving AI: two days of making videos with an AI agent (Claude Code or Codex) on your own computer.

- **Day 1:** a story, a Blender miniature, sound.
- **Day 2:** your own recording becomes a 60-second trailer: transcribe, clean sound, clone your own voice, motion graphics, B-roll, music, assemble.

One kit works on both Mac and Windows. Setup checks which one you're on.

## Get the kit (one prompt)

Open **Claude Code** (Claude desktop app › Code › choose your home folder) or the **Codex** app in your home folder, and paste:

> Set me up for the Agentic Creator Masterclass. Download https://github.com/surajdevarajwork-afk/agentic-creator/releases/latest/download/agentic-creator-starter-kit.zip into my Downloads folder and unzip it into my home folder, so I get a folder called `agentic-creator`. If that folder already exists, keep my files and only add what's missing. Then read `agentic-creator/START-HERE.md` and follow it with me, one step at a time.

Your agent downloads the kit, unzips it (about a minute) and walks you through setup. If it asks to use the internet, allow it.

## Rather click?

### Mac

1. [Download the kit](https://github.com/surajdevarajwork-afk/agentic-creator/releases/latest/download/agentic-creator-starter-kit.zip).
2. In Downloads, double-click the zip. Drag the `agentic-creator` folder into your home folder (Finder › Go › Home).
3. Claude desktop app › Code › open `agentic-creator` (or open it in Codex), and say: `Read START-HERE.md and set me up, one step at a time.`

### Windows

1. [Download the kit](https://github.com/surajdevarajwork-afk/agentic-creator/releases/latest/download/agentic-creator-starter-kit.zip).
2. In Downloads, right-click the zip › **Extract All…** Move the `agentic-creator` folder into your user folder (`C:\Users\<you>`).
3. Claude desktop app › Code › open `agentic-creator` (or open it in Codex), and say: `Read START-HERE.md and set me up, one step at a time.`

## What you need

- **Mac:** an Apple chip (M1 or newer) on macOS 15 or newer. Intel Macs can't run Blender 5, Diffusion Studio or voice cloning.
- **Windows:** Windows 10 or 11. An NVIDIA graphics card makes Blender and voice cloning faster, but you don't need one.
- About **25 GB** free.
- **Claude Code or Codex**, signed in.
- For Day 2: **two minutes of you talking to your phone camera**, landscape, unedited. Keep your fumbles in.

Never paste an API key into the chat. You'll make your keys in class.
